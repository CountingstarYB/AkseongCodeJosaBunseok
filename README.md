# 악성코드 조사분석 보고서 에이전트

악성코드 조사분석 사례를 정해진 항목으로 기록하고, 과거 유사 사례를 찾고, 기존 보고서 양식에 붙여 넣을 개조식 문안을 만드는 **오프라인 단일 HTML 도구**입니다.

## 바로 체험하기

**https://countingstaryb.github.io/AkseongCodeJosaBunseok/?demo** — 로그인 없이 가상 예시 사례 5건으로 둘러봅니다.

공개 시연 사이트에는 실제 사건 정보를 입력하지 마세요. 입력값은 그 브라우저에만 저장되고 어떤 서버로도 전송되지 않습니다.

## 실행 (폐쇄망)

`악성코드_조사분석_보고서_에이전트.html`을 Chrome으로 엽니다. 설치·서버·인터넷 연결이 필요 없습니다.

- 로그인 화면의 **[로그인 없이 체험하기]** 로 바로 둘러볼 수 있습니다.
- 초기 버전 체험용 계정: 아이디 `admin` / 비밀번호 `admin` (가상 데이터 시연 전용. 실제 운영 시 국방망 통합 인증으로 교체)
- 사례는 브라우저 저장소에 자동 저장되며, **[백업 내보내기]** 로 JSON 파일을 보관합니다.

## 주요 기능

- 사례 기록: 기본 정보, 파일·해시, 탐지 정보, 유입·탐지경위, 악성행위 체크리스트(23개 태그), 침해지표(자동 무력화 표기), 피해현황, 조치사항, 진행과정
- 유사 사례 찾기: 해시 일치 → URL·도메인 일치 → 행위패턴 겹침 순
- 보고서 문안: 1페이지(개요, 조사분석내용, 조치사항)와 세부내용(개요도, 진행과정, 침해지표, 악성코드)을 섹션별로 복사
- 라이트·다크 모드

## 파일 구성

| 경로 | 내용 |
|---|---|
| `악성코드_조사분석_보고서_에이전트.html` | 도구 본체 (로고 이미지 포함) |
| `PRD_악성코드_조사분석_보고서_도우미.md` | 요구사항 문서 |
| `assets/src/` | 로고 원본 |
| `assets/logo_*.png` | 배경 제거·축소한 로고 |
| `assets/build_assets.py` | 로고를 HTML에 다시 넣는 스크립트 (`python assets/build_assets.py`, Pillow 필요) |

## 주의

백업 JSON 파일에는 PC명·부서명·내부 IP 등 민감 정보가 포함될 수 있습니다. **백업 파일을 이 저장소에 올리지 마세요.** (`.gitignore`로 제외되어 있음)
